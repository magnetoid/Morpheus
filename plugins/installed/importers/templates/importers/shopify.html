What to import

What runs underneath

  • • Idempotent upserts via the SourceMapping table — every Shopify ID maps to a stable Morpheus record.
  • • Products preserve handles as slugs, variants by SKU, images sorted with the first as primary.
  • • Customers store only email + first/last name — no addresses or payment data are pulled.
  • • Orders import as status=pending with source=import; their original payment status flows through to payment_status.
  • • If the import fails halfway, re-running picks up where it left off — safe to retry.
