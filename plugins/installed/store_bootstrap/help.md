## What it's for
This is a one-prompt way to start a new store. Describe the kind of store you want in a sentence, and it generates a brand voice, a handful of categories, and ten to twelve starter products with names, descriptions and prices — all saved straight into the store, ready for you to edit.

## Set it up
It needs an AI provider connected in Settings → AI before it can generate anything; without one it tells you so instead of a result.

## Common tasks
- Open [](page:start) and describe your store in one sentence.
- Try one of the sample prompts if you're not sure what to write.
- Review the products it created, and edit anything you want to change.
- Run it again with a different sentence to add more categories and products on top of what you have.

## Good to know
Running the same sentence again does not create duplicates — it reuses the categories and products it already made and only adds what's new. Generating takes anywhere from a few seconds to half a minute while it waits on the AI provider. Nothing here replaces or deletes an existing product; it only adds new ones.
