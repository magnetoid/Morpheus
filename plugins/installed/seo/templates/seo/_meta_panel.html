{% comment %} The per-entity SEO panel — the SAME editor for products, categories, collections, CMS pages and journal posts. Contributed into each shell's form through PRODUCT_/CATEGORY_/COLLECTION_/PAGE_FORM_CARDS and persisted by seo.services.panel.save_object_seo(obj, request.POST); every field posts as seo_*, a namespace that cannot collide with the host form's own fields. Self-contained: a scoped IIFE drives the live Google + social previews and the counters, so the panel drops into any dashboard edit form. It mirrors the host form's own title/description/cover inputs when told their element ids (seo_host_title_id / seo_host_desc_id / seo_host_image_id), so the preview reflects what the merchant is typing above it even before they override it. Context: seo (values dict), seo_ai_answer, seo_robots_extra, seo_provenance, seo_noindex, seo_nofollow, seo_title_max, seo_desc_max, seo_twitter_choices, seo_brand, seo_host, seo_object_path. {% endcomment %}
