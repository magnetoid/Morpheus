What the policies mean

Keep indexable, drop from the canonical
The page still ranks, under the clean URL. Right for campaign tags and sorting: the same products, arrived at differently.
No-index this page
Crawl the links, don’t keep the page. The canonical stays on the URL itself, deliberately.
Index only the listed values
Turn the filters worth ranking for into landing pages, and hold back the combinations nobody searches for.
Block in robots.txt
The only policy that saves crawl budget, because the page is never fetched. It also means the page’s own directives are never read — so use it for parameters that should simply not be visited.
page
Has its own policy and takes no rule: page 2 stays indexable and canonical to itself, ?page=1 redirects to the clean URL, and a number past the end is a 404.
