## What it's for

Create a scheduled live event with an embedded video stream and pin the products you want to sell during it. The storefront lists upcoming and live events, and once you add a recording link, an ended event's page becomes a replay. Links from an event's product rail are tagged so you can trace sales back to that show.

## Common tasks

- Schedule a new event with a title, start and end time, and an embed link, from [Live shopping](page:live).
- Pin the products you want to sell during the show.
- Mark an event live when you start streaming, then ended when you finish.
- Add a recording link to an ended event to turn its page into a replay.
- Delete an event you no longer need.

## Good to know

The storefront only teases an upcoming or live event on the home page; nothing shows once every event has ended without a replay link. There is no built-in video hosting or chat — you supply the embed link to whatever stream you run elsewhere.
