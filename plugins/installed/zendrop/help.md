## What it's for

Zendrop does not offer a way for a store like this to send or track orders on its own, so this app keeps the manual work fast: it shows which of Zendrop's own tools your account token can reach, builds a ready-to-copy order sheet for every paid order, and lets staff record that an order was placed and ship it once Zendrop reports a tracking number.

## Set it up

Generate an access token in Zendrop for its own developer connection, with the orders and catalogue permissions, and paste it on [Zendrop dropshipping](settings:zendrop). Use "Test connection" on the [Zendrop](page:orders) page to confirm it works and see which tools it can reach.

## Common tasks

- Test the connection and see which Zendrop tools the token can reach.
- Open a paid order's order sheet and copy its address and item details into Zendrop.
- Mark an order as placed in Zendrop once you have done so there.
- Ship an order by typing in its tracking number, or upload a tracking file to ship several at once.
- Link an existing product to a Zendrop item on its edit page.

## Good to know

Nothing is sent to Zendrop automatically: every order is placed in Zendrop by hand, and tracking only reaches the customer once staff record it here, either one at a time or from a file. The connection test can keep showing an old result for up to an hour after the token is changed. Linking variants and reading the order sheet are the only things this app does on its own.
