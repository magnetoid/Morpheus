{% load seo %}{% comment %} Renders the primary product image as the PDP cover. Caller context: product — the GraphQL `product` dict (has .images = list of {url, altText, isPrimary}, .name, .slug, …) hero_image — optional pre-resolved primary image dict (the view computes this once via `next(... isPrimary ...) or images[0]`). If passed, we use it directly. If not, we fall back to iterating product.images. alt — fallback alt text (typically product.name) slug — product slug (used for view-transition-name) Placeholder card renders when no usable image exists. {% endcomment %} {# Pick the URL to render. hero_image wins; otherwise scan product.images. #} {% with hero_url=hero_image.url|default:'' %} {% if hero_url %}
{% with vt_name="cover-"|add:slug|slugify %} {% seo_responsive_image hero_url alt=hero_image.altText|default:alt widths="400,600,800,1200" sizes="(min-width: 900px) 480px, 90vw" priority=True view_transition_name=vt_name %} {% endwith %}
{% else %} {# Fallback: scan product.images for an isPrimary one (or the first). #} {% with picked=None %} {% for img in product.images %} {% if img.isPrimary and not picked %}{% with picked=img %}
{% with vt_name="cover-"|add:slug|slugify %} {% seo_responsive_image picked.url alt=picked.altText|default:alt widths="400,600,800,1200" sizes="(min-width: 900px) 480px, 90vw" priority=True view_transition_name=vt_name %} {% endwith %}
{% endwith %}{% endif %} {% endfor %} {# Last-resort: no isPrimary, use the first image if any. #} {% if product.images and not product.images.0.isPrimary %} {% with first=product.images.0 %} {% if first.url %}
{% with vt_name="cover-"|add:slug|slugify %} {% seo_responsive_image first.url alt=first.altText|default:alt widths="400,600,800,1200" sizes="(min-width: 900px) 480px, 90vw" priority=True view_transition_name=vt_name %} {% endwith %}
{% endif %} {% endwith %} {% elif not product.images %} {# No images at all — book-shaped placeholder. #}
{{ alt|default:product.name }}
{% endif %} {% endwith %} {% endif %} {% endwith %}
