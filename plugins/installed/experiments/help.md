## What it's for

This app can run a split test: show different shoppers a different version of something, then compare how often each version leads to a purchase, a cart add or a signup. One test ships already defined — comparing the existing checkout against a one-page version — but it has never been switched on, and nothing on the storefront currently shows either version based on it.

## Good to know

There is no screen in the dashboard for this yet, so nobody on staff can create a test, switch one on, or see its results from a page — that only happens today through code a developer writes and runs directly. A shopper who is signed in is tracked consistently across visits; one who is not signed in is not, so results for signed-out shoppers would not be reliable even once a test is running.
