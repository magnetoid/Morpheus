## What it's for

This app can give a curated set of two to six products ("a look") its own public page, showing the products together with a title, description and cover image. There is no dashboard screen for creating or editing a look, so one has to already exist in the database before this does anything. Each product in a look links to its own product page; a look page does not add the whole set to the cart at once.

## Good to know

A look that is not published, or whose address is wrong, shows the store's normal "not found" page. A "worn with" teaser meant to appear on a product page for looks that include it does not currently show anything. Turning this app off removes every look page.
