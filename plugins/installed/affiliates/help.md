## What it's for

People apply to your affiliate program, get a personal tracked link — and a coupon code, if you set one up for them — and earn a commission on the orders they bring in. Each affiliate gets their own area to see their clicks, conversions, and what they are owed, request a payout, and build embeddable product widgets for their own site.

## Set it up

[Affiliates](settings:affiliates) settings hold the defaults a new program starts from: [](field:affiliates.default_commission_percent), [](field:affiliates.cookie_window_days) (how long a click stays credited to that affiliate), and [](field:affiliates.min_payout_threshold). Create at least one program on [Programs](page:programs) before approving applicants.

## Common tasks

- Review and approve or reject applications from [Affiliates](page:list).
- Set a program's commission rate, tiers, and category overrides on [Programs](page:programs).
- Watch clicks, conversions, and sign-ups on [Analytics](page:analytics).
- Run a payout and mark payouts as paid from [Payouts](page:payouts).
- Give affiliates a creative to use from [Creatives](page:creatives).
- Ask Linda to list affiliates, see pending payouts, mark one paid, or create a new affiliate.

## Good to know

An order can be attributed to an affiliate either by their tracked link or by a coupon code tied to their account, so a shout-out that only mentions a code still counts. Commission can step up in tiers as an affiliate brings in more approved sales, and can be overridden for specific categories. A cancelled or refunded order claws its commission back. Payouts only run once an affiliate has earned at least the minimum threshold.
