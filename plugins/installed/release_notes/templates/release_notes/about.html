About Morpheus

The platform you're running — and every app inside it.

{# What is Morpheus — a subtle branded hero #}
Morpheus OS {{ version }}

Morpheus is an AI-first, modular commerce operating system. It runs your whole store — catalog, pricing, checkout, fulfillment — and stays deliberately swap-able: almost everything beyond the core commerce spine is an app you can switch on or off. Turn an app off and every surface it added — storefront blocks, dashboard pages, settings — disappears cleanly. Power through modularity, not a monolith.

{# Three surfaces #}

Three surfaces

Storefront

The shop your customers see — themeable, multi-market, and composed from blocks that apps contribute.

Dashboard

This console — where you run catalog, orders, customers, marketing, and settings.

Linda

The built-in AI operator — ask her to act on the store from the command bar or chat.

{# How it's built #}

How it's built

A clean core, everything else an app. The kernel handles only what every store needs — auth, the request lifecycle, the events bus, and the AI + self-improvement loop. Catalog depth, promotions, markets, B2B, subscriptions, sales channels — all apps.

Toggle-safe by design. Apps coordinate through an events bus, never by reaching into each other. Enable or disable one from Apps and the store reshapes itself — no dangling links, no broken pages.
