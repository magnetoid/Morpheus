Reading the numbers

  • Cache hit ratio measures how often Cloudflare answered without hitting the origin. 80%+ is healthy for a typical commerce surface; below 50% suggests cache-busting query params, short TTLs, or Cache-Control headers from Django defeating CF.
  • Bandwidth is bytes served by Cloudflare (cached + uncached). High bandwidth + low cache hit ratio = paying origin bandwidth you could be saving.
  • Threats blocked = Cloudflare's WAF / Bot Fight Mode counter. Spikes correlate with credential-stuffing or scraper attacks.
  • Cloudflare's own dashboard has per-country / per-status-code / per-content-type breakdowns. The CF link in the sidebar opens it.
