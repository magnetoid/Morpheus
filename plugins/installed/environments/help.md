## What it's for

This app can hold more than one named environment for your store — for example "Development", "Staging" and "Production" — and can remember a snapshot of one environment's theme choice and settings overrides so it can be copied onto another later, with the change recorded and reversible. Products, inventory, orders and customers are never part of this: they stay shared and live everywhere.

## Good to know

There is no screen in the dashboard for this yet. Nobody on staff can create an environment, take a snapshot, or copy one environment onto another from a page — that only happens today through code a developer runs directly. A connected system can ask the store's API which environments exist and what has been copied to one, but nothing more. Visiting the storefront never looks at this at all, so nothing here changes what a shopper sees.
