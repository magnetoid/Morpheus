{% comment %} The dashboard media uploader, form-bound mode: one image field of any form. Same component as the product gallery (_media_uploader.html) — same look (static/admin_dashboard/media-uploader.css), same script (static/admin_dashboard/media-uploader.js, data-mode="field") — but the chosen file travels with the form's own Save: it works on a create form, and it never reloads the page over unsaved edits. The X removes the image through Django's own clear checkbox (`-clear`, ClearableFileInput), so the view needs nothing beyond `Form(request.POST, request.FILES)`. Usage: {% include "admin_dashboard/_media_field.html" with field=form.image current=category.image label="Image" help="Shown on the category tile." %} A field outside a Django form passes `name` (and leaves `field` out); a file that is not only an image passes `accept`, `max_mb`, `note`, `add_text` / `replace_text`, and `current_document=True` when the stored file is not an image (it shows as a named file, linked, instead of a picture). `bare=True` drops the card frame inside another card. {% endcomment %} {% load i18n %}
