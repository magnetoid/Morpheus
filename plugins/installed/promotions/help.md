## What it's for

This app discounts a cart automatically — by cart total, country, customer group, product, or sales channel — without the shopper entering anything. A promotion can also be set to only fire when a specific coupon code is present. Every time one fires on an order, it is recorded so you can see how often it has been used.

## Common tasks

- Ask Linda to create a straightforward percent-off promotion — today this is the only kind anyone can create.
- See which promotions are running and how many times each has fired, on [Promotions](page:index).
- See the most recent orders a promotion discounted, on the same page.

## Good to know

The Promotions page itself only shows what exists. Linda can create a percent-off promotion, but nothing on screen or through Linda can change one yet. When more than one promotion could apply to the same cart, the one with the lower priority number runs first.
