## What it's for

This app lets you store extra pieces of information on a record that the store's own built-in fields don't cover — on a product, a product variant, a category, a collection, an order, an order item, a customer, or a content page. Some apps create their own custom fields this way too, for example to hold a book's ISBN or barcode. Wherever a record has any custom fields, they show in a "Custom fields" box right on its own edit page.

## Common tasks

- Change the value of a custom field already shown on a product, customer or order's edit page.
- Browse, search and filter every custom field store-wide from [Metafields](page:index).
- Add a brand new custom field, or delete one, from [Metafields](page:index).

## Good to know

A record's own edit page can only change a custom field that already exists on it; adding a brand new one, or deleting one, is done from the [Metafields](page:index) page, where you pick the exact record by its own ID number. Fields are grouped under a namespace — one you create yourself usually has none, while one an app creates for its own use usually carries that app's name. Linda can also look up and set custom fields on a record when asked to.
