{% comment %} Reusable 3D book viewer. Renders every `.book-3d[data-pdf-url]` element on the page: PDF.js rasterises page 1 of the cover PDF → a CanvasTexture on the front face of a three.js book; OrbitControls let the shopper drag to rotate. Loaded from CDN (unpkg) via an ES-module importmap — same no-build pattern as the bookstore_3d plugin. CSP: storefront is report-only; the dashboard CSP allows unpkg in script-src/connect-src/worker-src (see core/security_headers). Fail-soft: any load/parse error leaves a plain message, never a white box. Include this ONCE per page (it carries the importmap, which must be unique). {% endcomment %}
