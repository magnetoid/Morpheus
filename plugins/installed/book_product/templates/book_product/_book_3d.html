{% comment %} Reusable 3D book viewer. Renders every `.book-3d[data-cover-url]` element on the page as a three.js book: an image cover as it is (`data-cover-type="image"`), a PDF through PDF.js, which rasterises page 1 into a CanvasTexture. A cover is either the front alone or the whole wrap a printer takes (back | spine | front, left to right): a file wider than a front cover is a wrap, split across the back, spine and front faces, and the book's thickness is the spine's width. `data-width-mm`, `data-height-mm` and `data-spine-mm` (the book's own sizes) make the split exact; without them the spine is guessed. OrbitControls let the shopper drag to rotate. Loaded from CDN (unpkg) via an ES-module importmap — same no-build pattern as the bookstore_3d plugin. CSP: storefront is report-only; the dashboard CSP allows unpkg in script-src/connect-src/worker-src (see core/security_headers). Fail-soft: any load/parse error leaves a plain message, never a white box. Include this ONCE per page (it carries the importmap, which must be unique). {% endcomment %}
