{% comment %} Reusable 3D book viewer. Renders every `.book-3d[data-cover-url]` element on the page: the cover goes on the front face of a three.js book, an image as it is (`data-cover-type="image"`) and a PDF through PDF.js, which rasterises page 1 into a CanvasTexture; OrbitControls let the shopper drag to rotate. Loaded from CDN (unpkg) via an ES-module importmap — same no-build pattern as the bookstore_3d plugin. CSP: storefront is report-only; the dashboard CSP allows unpkg in script-src/connect-src/worker-src (see core/security_headers). Fail-soft: any load/parse error leaves a plain message, never a white box. Include this ONCE per page (it carries the importmap, which must be unique). {% endcomment %}
