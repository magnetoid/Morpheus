## What it's for

DSers does not connect to stores like this one directly, so this app is the bridge: it links your products to their AliExpress listings, then produces the file DSers expects for new orders and reads back the file DSers exports once an order has shipped. There is no live connection to DSers — every step is a file staff download from here and upload into DSers, or the other way round.

## Set it up

Nothing to connect: there is no account or key to enter here. On each product, use the "DSers supplier" card to note the AliExpress product URL and supplier SKU for each variant, then do the rest from the [DSers](page:orders) page.

## Common tasks

- Download the order file for every paid order ready to send, which also marks those orders as sent.
- Upload that file into DSers, where DSers places and pays the AliExpress order.
- Download the product-mapping file DSers needs to match your variants to its listings.
- Once DSers reports tracking, download its export and upload it here so the matching orders ship and the customer is told.

## Good to know

Nothing here happens on its own: every order still needs a member of staff to move the files between this store and DSers. If a sent order is later cancelled in the store, this app only notes that it also needs cancelling in DSers — it cannot do that part for you.
