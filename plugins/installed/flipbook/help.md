## What it's for

This app adds a flip-through preview of a digital product's PDF — an ebook or similar file — to its product page. A shopper clicks through to a reader page that flips like a real book, built from only the first pages of the file, never the full file you sell.

## Set it up

In [](settings:flipbook), [](field:flipbook.enabled) turns the preview on or off; when off, both the reader page and its button on the product page 404. [](field:flipbook.max_preview_pages) sets how many pages of the PDF the preview shows. [](field:flipbook.theme) sets the reader's background colour.

## Common tasks

- Attach a PDF as a product's digital file, or a digital variant's, to get the preview automatically — there is nothing else to turn on per product.
- Lower the number of preview pages if you want to show less of a book before someone buys it.
- Turn the preview off store-wide without removing the digital file itself.

## Good to know

The preview only appears for a product whose digital file, or first active digital variant, is a PDF; anything else shows no preview button. The reader page is built once and reused after that, and has its own title and description so it does not compete with the product page for the same search listing. The file you sell is never linked from the preview or the reader page — only staff can open it directly.
