Usage examples

Replace YOUR_TOKEN with any token from the table above.

MCP — JSON-RPC 2.0 (recommended for LLM agents)

curl -X POST {{ request.scheme }}://{{ request.get_host }}{{ admin_rpc_url }} \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0", "id": 1, "method": "tools/call",
    "params": {
      "name": "catalog.publish_digital_product",
      "arguments": {
        "title": "Crime and Punishment",
        "author": "Fyodor Dostoevsky",
        "pdf_url": "https://your-cdn.com/crime.pdf",
        "price_amount": "12.99"
      }
    }
  }'

GraphQL — typed schema (recommended for scripts)

curl -X POST {{ request.scheme }}://{{ request.get_host }}{{ graphql_url }} \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "mutation($i:UpdateProductInput!){updateProduct(input:$i){slug priceAmount status error}}",
    "variables": {"i": {"slug": "crime-and-punishment", "priceAmount": "7.99", "status": "active"}}
  }'
Same token, both surfaces. Behind the scenes the token resolves to a synthetic mcp-service staff user — every mutation is attributed to that user in audit logs.

Common product-lifecycle mutations

Same Bearer token for all of these.

Create a generic product

mutation($i: CreateProductInput!){
  createProduct(input: $i){ slug status error }
}
# variables: {"i": {"name": "...", "priceAmount": "29.99",
#                   "productType": "simple", "status": "draft"}}

Publish a PDF book (downloads PDF + cover)

mutation($i: PublishDigitalProductInput!){
  publishDigitalProduct(input: $i){ slug url error }
}
# variables: {"i": {"title": "...", "pdfUrl": "https://…/book.pdf",
#                   "coverImageUrl": "https://…/cover.jpg",
#                   "priceAmount": "9.99"}}

Replace the PDF on an existing digital product

mutation($i: UpdateDigitalPdfInput!){
  updateDigitalPdf(input: $i){ slug error }
}
# variables: {"i": {"slug": "your-book",
#                   "pdfUrl": "https://…/book-v2.pdf"}}

Flip draft → active

mutation($i: UpdateProductInput!){
  updateProduct(input: $i){ slug status error }
}
# variables: {"i": {"slug": "your-book", "status": "active"}}

Upload an image to a product

mutation($i: AddProductImageInput!){
  addProductImage(input: $i){ id url isPrimary error }
}
# variables: {"i": {"slug": "your-book",
#                   "imageUrl": "https://…/cover.jpg",
#                   "isPrimary": true, "altText": "Cover"}}

Remove or promote an image

mutation { removeProductImage(imageId: "uuid") { id error } }
mutation { setPrimaryImage(imageId: "uuid")    { id error } }
