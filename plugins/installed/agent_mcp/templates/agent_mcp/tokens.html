API tokens

A token lets another program or AI agent work with this store: Hermes Agent, OpenClaw, Claude Code, a script or an automation. One token works for the MCP server and the GraphQL API, and a token that may talk to Janus can ask the store's own agent anything. Give each agent its own token so you can revoke it alone.
