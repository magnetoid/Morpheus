## What it's for

This app can run a short piece of code at specific moments — working out a product's price or a cart's total — and feed the result back into the store. The code runs in a restricted environment that cannot read files, reach the network, or touch anything on the server beyond the handful of calculations it is explicitly given.

## Good to know

There is no screen in the dashboard to write or switch on one of these yet, so none run today unless a developer has created one directly in the database. A connected system can try out a piece of code and see what it would return without saving it, but cannot yet save or switch one on over the store's API either.
