## What it's for
This gives you one place to see who changed what and when across the dashboard — sign-ins, settings changes, AI actions and other recorded events. It is a read-only log, not a place to undo anything.

## Set it up
There is nothing to configure. Every recordable action in the dashboard is logged automatically once this app is on.

## Common tasks
- Open [](page:audit) to see recent activity across the store.
- Filter to just AI actions, or just security events such as sign-ins and permission changes.
- Search by event type or by what was changed.
- Filter by severity to find warnings or errors among ordinary activity.

## Good to know
This shows the most recent 200 matching entries at a time, so narrow the filters to find an older one. It only records events the rest of the store already chose to log, so it is not a record of absolutely everything that happened. The server and browser error log is a separate page, reached from Settings → Developer, not from here.
