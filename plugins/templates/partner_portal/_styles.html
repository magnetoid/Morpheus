{% comment %} The partner-portal stylesheet. partner_portal/base.html includes it in the theme's extra_head block, so it arrives before any markup it lays out (a style element after the content is a layout shift on a slow link). It is written against the token names every storefront theme defines (--paper, --paper-2, --ink, --ink-2, --muted, --rule, --accent, --accent-ink, --sans, --serif); a token only some themes have (--surface, --line-strong, --mono, --r-md) is read with a fallback, so the one stylesheet looks native under each theme. {% endcomment %}
