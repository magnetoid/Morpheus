# Apps consolidation, Wave 1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the ten apps that hold no data and show nothing, and the dead models in apps that stay, in two releases that keep the migration gate and the automatic rollback working.

**Architecture:** Release A (v0.122.0) takes everything out of the code: the ten app folders, their lines in `MORPHEUS_DEFAULT_APPS`, and the dead models out of Django's state only (`SeparateDatabaseAndState`). Every table stays, so a store the guard puts back on v0.121.0 still finds all of them. Release B (v0.122.1), pushed only once A is live on all four stores, drops the leftovers. A removed app's tables go from a `plugins` app migration through a new `core.migration_ops.DropLeftoverModel`, which drops a table only when it is there and empty. A staying app's tables go from its own migration (state-only `CreateModel`, then `DeleteModel`). Each Release B migration carries `morpheus_contract`.

**Tech Stack:** Django 6.1 migrations (`SeparateDatabaseAndState`, a `DeleteModel` subclass), the migration gate (`core/migration_safety.py`, v0.119.0), `manage.py release`, the CI ratchets (`scripts/check_plugin_standard.py`, `scripts/check_plugin_boundary.py`).

**Spec:** [`docs/plans/apps-consolidation-2026-10.md`](../../plans/apps-consolidation-2026-10.md), "Wave 1: delete what does nothing" (owner, 2026-10-12). The order is changed from the spec's (owner "go", 2026-10-22). The spec drops the tables first and removes the apps a release later. Since v0.119.0 the gate refuses that, and a store put back on the release before would boot against missing tables. So the code goes first and the tables a release later.

## Global Constraints

- A push to `main` deploys all four stores. Each release runs `manage.py release` (version bump plus a dated `docs/RELEASE_NOTES.md` entry).
- Release B is pushed only after Release A serves on all four stores. Its contract says the previous release reads none of those tables, which is true only of A.
- A migration the previous release could trip over carries `morpheus_contract = "<why it is safe>"`. Without one, `release` and `release --check` refuse it (`core/migration_safety.py`).
- The pre-commit hook refuses the uppercase SQL statement that drops or truncates a table in any added line, docs included (`core/safety.py` `PRECOMMIT_FORBIDDEN_PATTERNS`). Tables are dropped only through Django's `DeleteModel`. No document or comment spells the statement out.

- Live checks read only, except the two named writes: Task 5 (the lumina page on dotbooks) and Task 7 (the junk rows, backed up first). Never `force_login` on a store.

`core/migration_ops.py`:

```python
"""Migration operations for taking apart what an earlier release removed
(apps consolidation, docs/plans/apps-consolidation-2026-10.md).

A removed app's code leaves in one release and its tables in the next, so the release
before still runs on the schema. ``DropLeftoverModel`` is that second step: a
``DeleteModel``, so the migration gate (core/migration_safety.py) asks for a
``morpheus_contract`` as it does for any other table it drops. It leaves a database
alone when the table is not there (a store created after the app left, the test
database) and keeps a table that still holds rows: they belong to someone, and a
person decides what happens to them.
"""

from __future__ import annotations

import logging

from django.db import migrations

logger = logging.getLogger('morpheus.migrations')


class DropLeftoverModel(migrations.DeleteModel):
    reversible = False  # a dropped table comes back from a backup, not from a migration

    def database_forwards(self, app_label, schema_editor, from_state, to_state):
        model = from_state.apps.get_model(app_label, self.name)
        connection = schema_editor.connection
        table = model._meta.db_table
        if table not in connection.introspection.table_names():
            return
        with connection.cursor() as cursor:
            cursor.execute(f'SELECT 1 FROM {schema_editor.quote_name(table)} LIMIT 1')  # noqa: S608 — the migration's own table name
            if cursor.fetchone() is not None:
                logger.warning(
                    'migrations: %s still holds rows, so it is kept; nothing reads it any more',
                    table,
                )
                return
        super().database_forwards(app_label, schema_editor, from_state, to_state)

    def describe(self):
        return f'Drop the leftover table of {self.name} when it is there and empty'
```

## Appendix C — `w1_junk.py` (each store, writes, after Release A)

```python
"""Apps Wave 1: back up, then delete, the two kinds of rows we know are not data."""
import json
from pathlib import Path

from django.apps import apps
from django.db import connection

from core.deploys import backup_root

out = backup_root() / 'wave1'
out.mkdir(parents=True, exist_ok=True)
existing = set(connection.introspection.table_names())


def dump(table):
    with connection.cursor() as cursor:
        cursor.execute(f'SELECT * FROM {connection.ops.quote_name(table)}')
        cols = [c[0] for c in cursor.description]
        rows = [dict(zip(cols, r)) for r in cursor.fetchall()]
    (out / f'{table}.json').write_text(json.dumps(rows, default=str, indent=1))
    return len(rows)


with connection.cursor() as cursor:
    if {'experiment', 'experiment_assignment', 'experiment_exposure'} <= existing:
        dump('experiment')
        cursor.execute('SELECT (SELECT count(*) FROM experiment_assignment) + (SELECT count(*) FROM experiment_exposure)')
        if cursor.fetchone()[0] == 0:
            cursor.execute("DELETE FROM experiment WHERE key = 'checkout_flow' AND status = 'draft'")
            print('W1JUNK experiment:', cursor.rowcount, 'deleted')
        else:
            print('W1JUNK kept experiment: it has assignments or exposures')
    if {'journal_post', 'journal_block'} <= existing:
        dump('journal_post')
        dump('journal_block')
        cursor.execute('SELECT slug FROM journal_post')
        slugs = [r[0] for r in cursor.fetchall()]
        Page = apps.get_model('cms', 'Page')
        live = set(Page.objects.filter(slug__in=slugs, state='published', metadata__category='journal')
                   .values_list('slug', flat=True))
        if slugs and set(slugs) == live:
            cursor.execute('DELETE FROM journal_block WHERE post_id IN (SELECT id FROM journal_post)')
            blocks = cursor.rowcount
            cursor.execute('DELETE FROM journal_post')
            print('W1JUNK journal:', cursor.rowcount, 'posts,', blocks, 'blocks deleted')
        elif slugs:
            print('W1JUNK kept journal: not every post has a published CMS journal page', sorted(set(slugs) - live))
print('W1JUNK backed up to', out)
```
